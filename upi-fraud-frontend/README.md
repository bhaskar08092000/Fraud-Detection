# Sentinel — UPI Fraud Intelligence Frontend

A beginner-friendly, responsive frontend prototype for the CC6-AI02 hackathon problem, built using **HTML, CSS and plain JavaScript**. No React, package install, build tool or paid library is required.

## Run it

1. Extract the ZIP (if you downloaded it).
2. Open the `upi-fraud-frontend` folder in VS Code.
3. Open `index.html` in a browser. The simplest option is the VS Code **Live Server** extension, then right-click `index.html` and select **Open with Live Server**. Direct browser opening also works for the main UI.
4. Select **Payment checker** or choose a scenario card on the Overview page.
5. Load a sample scenario and click **Analyse transaction**.
6. Open **Fraud alerts** to search/filter records or export them to CSV.

## What's included

- Overview dashboard with demo metrics, trend chart, fraud category bars, quick scenarios and recent alerts.
- Payment simulator form.
- Fake refund / collect request, QR recipient mismatch, remote-access, mule-account and legitimate-payment presets.
- Transparent JavaScript risk rules with plain-language explanations.
- Risk gauge and suggested intervention.
- Searchable/filterable alert queue and CSV export.
- Analyst status updates (new / under review / marked legitimate).
- Model insight page explaining placeholder metrics and the detection pipeline.
- Responsive layout for desktop, tablet and mobile.

## Important limitations

- This is a **frontend-only simulation**. It does not connect to a bank, UPI app, QR camera, device telemetry or backend API.
- The risk score is generated by illustrative JavaScript rules. It is **not a trained ML model** and is not a production fraud decision.
- Dashboard performance figures are illustrative placeholders. Replace them with measurements from a labelled test set before using them in your hackathon presentation.
- Sample transactions and payee IDs are fictional. Do not enter PINs, OTPs, passwords or real banking credentials.
- The alert queue is kept in browser memory for the current page session and resets when the page is reloaded. CSV export downloads a copy of the current demo records.

## File guide

- `index.html` — page structure and forms.
- `style.css` — layout, colours, responsive behavior and component styling.
- `script.js` — page navigation, scenario presets, demo risk rules, results, alert list and CSV export.
