    About this prototype

    Sentinel is a frontend demonstration for the CC6-AI02 payment-fraud hackathon challenge. It uses fictional data and transparent JavaScript rules to demonstrate the user journey.

    ✓ Payment simulator and scenario presets✓ Rule-based risk score with readable reasons✓ Searchable alert queue and CSV export○ No live UPI, bank API or trained ML model is connected
